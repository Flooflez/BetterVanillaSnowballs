# Better Snowball Fights

This Vanilla compatible mod allows snowballs (and other projectiles!) to do damage through a custom gamerule, making it possible to have actual snowball fights in Minecraft.  
<p align="center">
  <img src="https://github.com/Flooflez/BetterVanillaSnowballs/blob/1.21/assets/snowball_fight.gif?raw=true" />
</p>
This mod can be installed on the client to be used in Single Player and Open to LAN worlds, or on a Fabric server.

## How to use this mod
| Gamerule                                                                           | Description                                                               |
|------------------------------------------------------------------------------------|---------------------------------------------------------------------------|
| snowballDamage, eggDamage, fishingBobberDamage                                     | Sets the damage when hit with the projectile                              |
| snowballsOnlyDamagePlayers, eggsOnlyDamagePlayers, fishingBobbersOnlyDamagePlayers | Toggle the modded damage only when fighting players                       |
| snowballKnockback, eggKnockback, fishingBobberKnockback                            | Increase the amount of knockback provided when hit with the projectile    |
| fishingPullMultiplier                                                              | Increase the pull strength of the fishing rod                             |

**Only the host needs to have this mod installed, clients can join the fight without needing to install the mod.**

## Installation Instructions (Single Player Worlds)
1. Go to the [FabricMC website](https://fabricmc.net/use/installer/) and download the latest installer
2. Run the JAR, a window will pop up. Choose the correct version of Minecraft and loader, and click on "Install".
3. A new game version and profile will be created in the launcher's menu, which you can now use to launch Fabric.
4. Go to [Modrinth](https://modrinth.com/mod/fabric-api) or [Curseforge](https://www.curseforge.com/minecraft/mc-mods/fabric-api) and download Fabric API.
5. Place the Fabric API Jar and the Better Vanilla Snowballs Jar into your "mods" folder
6. Run the newly installed profile from step 3
## Installation Instructions (Server)
This mod works on both a dedicated server and in Single Player worlds.
<br/>To create a fabric server, please follow these instructions on [The Fabric Website](https://fabricmc.net/use/server/).
